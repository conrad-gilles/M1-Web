# Claude instructions

Follow `AGENTS.md` and `best-practices.md`. This project uses Angular 22 standalone components, `inject()`, Signals, Reactive Forms, and native `@if`/`@for` control flow. Keep shared infrastructure in `src/app/shared`. Preserve `../Documentation/API_CONTRACT.md` and `../Documentation/SYNC_PROTOCOL.md`; if a route or a Socket.IO event must change, change `backend/` in the same mission and update the matching document. The server is the single source of truth for playback: buttons and the browser's native controls send commands, the player only applies the shared state. Every play, pause or seek the player does itself goes through `selfPlayElement` / `selfPauseElement` / `selfSeekElement`, so its events are not mistaken for user actions; never touch `play()`, `pause()` or `currentTime` directly, or you create echo loops.

The interface has a light and a dark theme: never hard-code colours in component CSS, use the variables defined in `src/styles.css` (`var(--text)`, `var(--card-bg)`, `var(--error-bg)`…) and add new ones there for both themes. The interface is bilingual (French and English). Never hard-code user-visible text: add a key to `FR` and `EN` in `src/app/shared/i18n/translations.ts` (the `EN` type rejects a missing translation) and display it with `t('key')` from `I18nService`. A new French message sent by the backend must also be added to `SERVER_MESSAGES_EN`. Unit tests run in French (`src/test-setup.ts`), e2e tests too (`locale: "fr-FR"`); English is covered by `i18n.service.spec.ts`, `app.spec.ts` and `e2e/tests/langue.spec.js`.
